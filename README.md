# Taxi Multi‑Agent System (MAS) — рабочий демо‑проект для доклада

Это **полностью запускаемый** симулятор такси как **мультиагентной системы**.

Внутри есть:
- агенты **Driver** (водители), **Passenger(Request)** (пассажиры/заявки), **Dispatcher** (диспетчер/маркетплейс)
- дискретная симуляция на **клеточном городе** (grid) с манхэттенским расстоянием
- 2 стратегии матчинга:
  - `greedy` — ближайший водитель (простая базовая)
  - `auction` — мини‑аукцион: водители **делают ставки**, диспетчер выбирает минимум *стоимости* (расстояние + штрафы)
- динамическая цена (surge) от соотношения спрос/предложение
- ребалансировка пустых водителей в "горячие" зоны спроса
- сбор метрик + опциональные графики

## Быстрый старт

### 1) Установка зависимостей
```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
source .venv/bin/activate

pip install -r requirements.txt
```

### 2) Запуск симуляции
```bash
python -m taxi_mas.main --strategy auction --plot
```

### 3) Примеры
Быстрый прогон:
```bash
python -m taxi_mas.main --steps 600 --n-drivers 40 --request-rate 2.2 --strategy greedy
```

Сравнение стратегий (один и тот же seed):
```bash
python -m taxi_mas.main --seed 7 --strategy greedy
python -m taxi_mas.main --seed 7 --strategy auction
```

## Что показывать на докладе (структура)

1) **Постановка**: городской грид, заявки, водители, цель (минимизация ожидания / увеличение выполнения / справедливость и т.д.)
2) **Агенты**:
   - Driver: состояние (idle/в пути/с пассажиром), политика принятия заказа, ребалансировка
   - Passenger(Request): терпение (patience), отмена при ожидании
   - Dispatcher: сбор заявок, выбор пары "водитель‑пассажир", динамическая цена
3) **Протокол взаимодействия**:
   - пассажир публикует Request
   - диспетчер запускает matching
   - водитель получает offer → делает bid (для auction) → подтверждение
4) **Метрики**:
   - среднее ожидание (wait time)
   - доля отмен
   - загрузка водителей (utilization)
   - средний доход водителя
5) **Эксперименты**: варьируем `request-rate`, `n-drivers`, сравниваем `greedy` vs `auction`

## Архитектура папок

```
taxi_mas/
  __init__.py
  main.py          # CLI, запуск, отчет, графики
  sim.py           # симулятор и цикл времени
  agents.py        # Driver, Request (Passenger)
  dispatcher.py    # Dispatcher + стратегии matching
  city.py          # грид-город, расстояния, перемещения
  metrics.py       # сбор метрик
  utils.py         # генераторы, poisson и т.п.
```

## Идеи для расширения (если захотите "вау" в будущем)
